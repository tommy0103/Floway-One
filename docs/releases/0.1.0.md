# Floway 0.1.0

- Check for application updates from Settings. Downloads happen in the background, with visible download and verification states.
- Review release notes in the application and choose when to update and restart. Restarting briefly interrupts the local API service.
- Ready updates remain available in Settings after choosing Later. Installation uses the existing signed-package checks and database recovery point.

## 中文

- 可从设置中检查应用更新，后台下载时显示下载与验证状态。
- 可在应用内查看更新内容，自行选择更新时间。更新重启时，本机 API 服务会短暂中断。
- 选择“稍后”后仍可从设置中安装，安装沿用现有签名校验与数据库恢复点流程。
