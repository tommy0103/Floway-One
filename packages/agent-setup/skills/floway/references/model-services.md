# Model services in Upstreams

Read `concepts.md` first. The owner may say provider or model service; **Upstreams** is Floway's page label. Search the list before creating another connection. The list shows enabled state, model count/cache state, and routing priority. A disabled service's cached count is not evidence it currently serves traffic.

For a new service, activate **New upstream** and choose the provider type visible in the app. Inspect the form before entering anything: provider-specific fields vary. For a custom service, identify **Upstream name**, **Base URL**, **Authentication**, **API key**, **Fetch upstream models**, **Catalog path**, and **Default LLM endpoints**. The four selectable text endpoint formats are OpenAI Completions, OpenAI Chat Completions, OpenAI Responses, and Anthropic Messages. Select only formats supported by evidence for the chosen model and auth style. The direct helper's `probe-custom` checks them with minimal user-only requests; an error from a request containing `developer` role is a separate compatibility question, not proof an endpoint is unsupported. If the GUI is the chosen surface, use its controls and Playground to validate, or ask before switching to a direct probe.

Check the base URL/path relationship before saving. Floway can append its default `/v1` paths. A service URL ending in `/v1` or `/v1/` may need that suffix removed when defaults are used; custom catalog or path overrides may require it. Inspect **API paths**, **Catalog path**, and **Path overrides** before changing the URL. Do not silently normalize an existing configuration.

After saving, inspect the service's detail view and **Models** section. Refresh the catalog if needed and report the listed model IDs and enabled state. Then make a short request with a representative chat model through Playground (or the helper in direct mode) to confirm actual routing. For an agent request that fails on `developer` role after a minimal request succeeds, inspect **Upstream feature flags** > **Rewrite developer Roles to system**. Treat changing that flag as a scoped compatibility edit, verify by retrying the original request, and leave endpoint selection intact.

Editing enabled state, routing priority, disabled models, or a credential can affect existing clients. Identify the exact service and explain the effect before saving; verify the row or editor after refresh. **Delete upstream** is irreversible from this screen, so identify the service and confirm the owner's intent. Do not expose provider credentials in tool output or screenshots.
